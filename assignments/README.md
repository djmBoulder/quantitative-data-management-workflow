# Assignments

This folder contains shared assignment materials, including the [capstone portfolio](capstone-data-management-portfolio.md). Module-specific assignments live in `modules/`.

Submit all required assignments in Canvas. Module assignments count as badge evidence. Complete one primary Stata or R pathway, or choose the optional dual pathway. See the [course policies](../syllabus/course-policies.md) for the semester completion window, two allowed capstone revisions, and badge issuance process. No peer review is required.

The capstone offers course-provided synthetic data (Option A) or instructor-approved publicly distributable student-selected data (Option B). For Option B, submit the [data proposal](capstone-data-proposal.md) in Canvas before beginning work with those data. Both options use the same rubric. Module 06 and 07 evidence can cover specified skills that do not apply to the approved project, as described in the full assignment.
