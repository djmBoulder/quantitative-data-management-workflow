# Rubrics

These rubrics evaluate required module assignment evidence and the capstone portfolio. Review the student's primary Stata or R pathway, or both workflows if the student chooses the optional dual pathway.

Record feedback and grades in Canvas. A passing capstone grade records badge completion once the required course evidence demonstrates competency. The instructor then notifies the micro registrar to issue the badge. See the [course policies](../syllabus/course-policies.md).
