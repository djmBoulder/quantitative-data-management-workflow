# 10 Capstone Checklist

Use this checklist with the [full capstone assignment](../../assignments/capstone-data-management-portfolio.md) before submitting your portfolio.

## Data Option And Software Pathway

- [ ] I identified Option A (course-provided synthetic data) or Option B (instructor-approved student-selected data).
- [ ] For Option B, I received approval through the [data proposal](../../assignments/capstone-data-proposal.md) before beginning the capstone with those data.
- [ ] For Option B, my approved files are publicly distributable, and I recorded sources, versions, redistribution terms, and required attribution.
- [ ] My inputs contain no private, restricted, confidential, identifiable respondent data, student records, or data whose terms prohibit redistribution.
- [ ] I identified my primary Stata or R pathway. If I chose the optional dual pathway, both scripts implement the same major decisions with the same inputs.

## Reproducible Script And Source Files

- [ ] I submitted one complete primary-pathway script and a log or text record of its run.
- [ ] My script runs from the documented project root, uses relative paths, and creates needed output folders.
- [ ] The instructor can obtain the exact approved inputs using the included permitted copies or agreed retrieval instructions.
- [ ] I preserved source files without manual edits and documented the files used.
- [ ] My script recreates the final outputs without manual edits.

## Cleaning, Missing Data, And Analytic Sample

- [ ] I inspected names, types, values, identifiers, and units of observation before cleaning.
- [ ] I performed meaningful cleaning and recoding or variable derivation, preserved source meaning, and checked the changes.
- [ ] I handled special missing codes when present and summarized missingness. I documented when none were present.
- [ ] I created an analytic sample flag before any exclusions, explained inclusion rules, and tracked observation counts.

## Reshape, Append, And Merge Evidence

- [ ] I identified evidence for all three skills in my memo, including exact filenames and script sections or Canvas assignment references.
- [ ] For Option A, I appended both person-level files and checked compatibility, observation counts, and respondent-year identifiers.
- [ ] For Option A, I merged regional context and checked region identifiers, duplicates, observation counts, and matched/unmatched cases.
- [ ] For Option B, I performed and checked each operation that applies to the approved workflow.
- [ ] For any operation that does not apply, I explained why and cited the approved Module 06 (reshape) or Module 07 (append and/or merge) evidence.
- [ ] The cited module evidence demonstrates the required skills, and any feedback requiring correction has been addressed.
- [ ] Any changes to the approved Option B sources, scope, or evidence plan were confirmed with the instructor in Canvas.

## Quality Checks And Outputs

- [ ] My QA report shows results for observation counts, required variables, identifiers, duplicates, missingness, valid ranges/categories, sample rules, and applicable transformations.
- [ ] I documented warnings and unresolved issues.
- [ ] I generated an analysis-ready dataset and codebook that explains source and derived variables.
- [ ] My memo explains the analytic purpose, source files, software pathway, data decisions, evidence locations, limitations, and rerun instructions.
- [ ] For Option B, I included the approved proposal and source documentation.
- [ ] I kept student-selected data and generated working/output/log files out of the course repositories.

## Submission And Badge Completion

- [ ] I submitted all required Module 00–09 assignments in Canvas as badge evidence.
- [ ] I submitted the capstone portfolio in Canvas by the posted cutoff.
- [ ] I understand that two capstone revisions are allowed after the initial submission, within the completion window.
- [ ] I know that a passing capstone grade records completion after the required course evidence demonstrates competency, and the instructor then notifies the micro registrar to issue the badge.
- [ ] I understand that peer review is not required and the dual pathway is optional.
