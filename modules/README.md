# Modules

Begin with Module 00, then work through the sequence below. In each module, read the overview and lesson, run the lab for your primary pathway, complete the assignment, and use the checklist before submitting in Canvas. The optional dual pathway adds practice in the second language.

| Module | Topic |
| --- | --- |
| [00](00-orientation/README.md) | Orientation and software setup |
| [01](01-project-workflows/README.md) | Project workflows and reproducibility |
| [02](02-importing-data/README.md) | Importing and inspecting data |
| [03](03-data-documentation/README.md) | Data documentation and codebooks |
| [04](04-cleaning-and-recoding/README.md) | Cleaning and recoding variables |
| [05](05-missing-data/README.md) | Missing data and analytic samples |
| [06](06-reshaping-data/README.md) | Reshaping data |
| [07](07-combining-data/README.md) | Appending and merging datasets |
| [08](08-quality-assurance/README.md) | Quality assurance checks |
| [09](09-reproducible-outputs/README.md) | Reproducible outputs and handoff files |
| [10](10-capstone/README.md) | Capstone portfolio |

Each module contains `README.md`, `lesson.md`, `stata_lab.do`, `r_lab.R`, `assignment.md`, and `checklist.md` for students. This review copy also includes clearly labeled `solution_notes.md` for teaching staff. See the [schedule](../syllabus/course-schedule.md) for workload and pacing, and the [course policies](../syllabus/course-policies.md) for completion requirements.
