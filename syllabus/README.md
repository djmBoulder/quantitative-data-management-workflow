# Syllabus

This folder contains the course description, schedule, learning objectives, assessment plan, badge competencies, and [course completion and badge policies](course-policies.md).

Canvas holds enrollment, the scaffolded module sequence, assignment submissions, feedback, and grades. Students complete one primary Stata or R pathway. The dual pathway is optional. Module assignments count as required badge evidence. The capstone allows two revisions after the initial submission, within the semester completion window. No peer review is required.
