# Quantitative Data Management and Workflow for Social Scientists

This is the public faculty review copy of the course, including instructor guidance and clearly labeled solution notes.

A course in reproducible data management for graduate students in the social sciences and anyone preparing for graduate-level quantitative methods courses taught in Stata or R. No prior coding experience is required.

Donald Mather, Statistics Consultant, Computing & Research Services, Institute of Behavioral Science, University of Colorado Boulder

## What You Will Learn

The course moves from project organization and importing data through documentation, cleaning, missing values, reshaping, appending and merging, quality checks, and reproducible outputs. You will practice protecting source files, recording decisions in code, and preparing an analysis-ready dataset another researcher can recreate and understand.

Modules 00–10 include orientation, nine technical modules, and a capstone. Each module provides an overview, lesson, Stata lab, R lab, assignment, and competency checklist. The estimated workload is **36 to 48 hours** in one primary software pathway. See the [course schedule](syllabus/course-schedule.md).

## Stata And R Pathways

Choose **Stata or R** for graded work. The parallel examples teach the same data-management skills in both languages. Review the other pathway conceptually; completing both sets of scripts is optional and requires additional time.

## Assignments, Capstone, And Badge

In the enrolled course, Canvas will hold the module sequence, submissions, feedback, and grades. All Module 00–09 assignments count as required badge evidence. Module 10 brings these skills together in a [capstone data management portfolio](assignments/capstone-data-management-portfolio.md): a reproducible script, analysis-ready data, codebook, quality checks, log, and workflow memo.

The capstone offers two data options:

- **Course-provided synthetic data:** use the supplied survey-style teaching files.
- **Approved student-selected data:** use publicly distributable data relevant to your work, after submitting the [data proposal](assignments/capstone-data-proposal.md) in Canvas and receiving approval.

Both options use the same [rubric](rubrics/capstone-rubric.md). Module 06 can demonstrate reshaping when it is not part of the capstone. For the approved student-selected option, Module 07 can demonstrate append or merge when that operation does not apply. All module assignments remain required.

The completion window runs from registration until **seven calendar days before CU's semester grade-submission deadline**, with the exact cutoff posted in Canvas. Two capstone revisions are allowed after the initial submission. No peer review is required. A passing capstone grade, supported by the required module evidence, records completion; the instructor then notifies the micro registrar to issue the badge. See the [course completion and badge policies](syllabus/course-policies.md).

## Teaching Data

All bundled data are synthetic and contain no real respondents. Use the assigned files for labs and Module 00–09 assignments. Keep approved student-selected capstone inputs and generated files out of GitHub; submit requested evidence in Canvas. Private, restricted, confidential, identifiable respondent data, student records, and data whose terms prohibit redistribution are not eligible. See the [data policy](syllabus/course-policies.md#capstone-data-options).
