# Data

This folder is reserved for synthetic teaching data and approved publicly distributable data only. Student-selected capstone inputs may be kept locally in the ignored `data/raw/` folder after proposal approval, but must not be committed to either course repository. Do not store private, restricted, confidential, identifiable respondent data, student records, or data whose terms prohibit redistribution here. See the [data policy](../syllabus/course-policies.md#capstone-data-options).
